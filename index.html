第一步：注册账户

  1. 1确保网络环境稳定，全程不要中断。打开 致富证券邀请链接，跳转后点【确定】，邀请码会自动填上；没有的话手动填 PP001
  2. 2页面拉到底部，把语言换成【简体中文】
  3. 3输入手机号 → 点【获取验证码】→ 做一次人机验证 → 填 6 位短信验证码 → 点【登录/创建账户】
  4. 4弹出的人机验证（滑块或拼图），完成即可
  5. 5设置登录密码（填两遍）→ 点【下一步】，就进入开户页面了
💡 开户过程中遇到问题，可以联系我们协助。

第二步：线上开户流程

  1. 1证件选择【内地身份证】，右边可以看一下开户要求 → 点【下一步】
  2. 2四个复选框全部勾上 →【下一步】
  3. 3账户类型选【保证金账户】→ 页面拉到底部，【综合购买力】要勾上 →【下一步】
  4. 4提交身份证正反面 → 检查身份证信息是否正确（身份证照片要清晰，四角完整，不要反光）
  5. 5填手机号（+86 或香港手机号都行）和邮箱 → 教育程度如实选择 → 住宅地址填身份证地址，用中文填写 →【下一步】
  6. 6职业状况、财务状况如实选择 →【下一步】→ 投资经验和目标如实选择。页面拉到底部，衍生品交易选【是】 →【下一步】→ 下一页直接点右上角的【跳过】
  7. 7税务编号填身份证号码 →【下一步】→ 接下来两页都选【否】→【下一步】→ 检查所有信息
  8. 8人脸识别：点【开始人脸识别】→【确定】→ 给相机权限点【允许】→ 完成识别
  9. 9认证内地银联卡：输入 62 开头的银联卡号和手机号 →【下一步】→ 风险披露把音频听完才能继续 → 签名、输入确认码 →【提交开户申请】→【确定】
✅ 之后等审核就行，实测很快就会通过：先收到审核通过的短信，账户号码（53 开头的一串数字）会发到你的注册邮箱。

第四步：入金拿奖励

港币入金：eDDA 秒到

  1. 1首页点【立即入金】→ 选【港元】→ 选【eDDA 即时入金】
  2. 2第一次要先绑定银行账户：点下拉框选银行，币种选【港币】，账户号码填储蓄账户号码（以汇丰为例，040 开头那串，去掉横杠、只填数字）。账户名称填姓名；开户证件选办港卡时用的证件 → 点【递交】→ 收短信验证码
  3. 3点【查看绑定状态】，几秒钟就显示【已绑定】
  4. 4点底部【立即入金】→ 支账银行会自动选好 → 填金额（按当期奖励档位来）→ 点【递交】，实测几乎秒到账

美元入金：网银转账（无损）

  1. 1【立即入金】→ 选【美元】→ 点下拉框选【环球】→【SIPC 环球股票账户】→【下一步】→ 选【网上银行转账】，会显示致富的美元收款信息。收款行有汇丰、中银香港和恒生，用这三家转账都是无损的
  2. 2以香港汇丰为例：打开汇丰 App → 点【转账】→ 提款账户选【美元储蓄】→ 点【转账至新收款人】→ 把致富的收款账号粘贴过去
  3. 3填金额 →【继续】→【确认】→ 点【存储详情】把转账凭证存到相册，凭证不要打码
  4. 4回到致富 App 点【已转账，通知致富】→ 填对应金额 → 上传凭证 →【递交】→【确认】。超过当天入金截止时间就要第二天到账
💡 没有美元？港币直接兑换：首页点【全部】→【转账/兑换】→ 转出选【港股保证金账户】→ 填金额 → 转入选【SIPC 环球股票账户】→【提交】。实测汇损不算大，兑换速度很快。

出金实测

先添加银行账户（提前做）

出金前要先添加收款的银行账户，审核要 2~3 天，这一步要提前做。

  1. 1首页【全部】→【银行账户】→ 点虚线框里的【新增】→ 币种选【港币】→ 选银行（港币出金到任何香港银行都零损）
  2. 2账户号码填储蓄账户号码 → 上传月结单（不要打码）→ 输入身份证首三位 + 登录密码 →【确认】，等待审核约两天

港币出金与美元出金

  1. 3港币出金：【全部】→【提款】→ 币种选【港元】→ 港股保证金账户 → 选银行 → 填金额 →【提交】。实测约一天到账，到任何香港银行都零损
  2. 4美元出金：【提款】→ 提款账户选【SIPC 环球证券账户】，币种自动变成美元 → 选银行 → 填金额 →【提交】。每天下午 2 点前处理，约一两天到账，出到汇丰无损
